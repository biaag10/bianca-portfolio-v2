# Bem-vindo ao Projeto do Portfolio Pessoal de Bianca

## Sobre o Projeto

Este projeto foi desenvolvido como parte do meu portfólio pessoal, com o objetivo de demonstrar minhas habilidades técnicas, capacidade de resolução de problemas e familiaridade com ferramentas e carreira profissional.

## Informações do Projeto

**URL**: https://github.com/biaag10/bianca-portfolio-v2.git

Siga os passos:

```sh
# Passo 1: Clone o repositório usando a URL do GitHub
git clone https://github.com/biaag10/bianca-portfolio-v2.git

# Passo 2: Navegue para o diretório do projeto
cd bianca-portfolio-v2

# Passo 3: Instale as dependências necessárias
npm install 
ou 
npm i

# Passo 4: Inicialize o projeto
npm run dev
```

**Editar um arquivo diretamente no GitHub**

- Navegue até o(s) arquivo(s) desejado(s);
- Clique no botão “Editar” (ícone de lápis) no canto superior direito da visualização do arquivo;
- Faça as alterações necessárias e confirme (commit) as mudanças.

**Usar o GitHub Codespaces**

- Vá até a página principal do repositório;
- Clique no botão “Code” (botão verde) próximo ao canto superior direito;
- Selecione a aba “Codespaces”;
- Clique em “New codespace” para iniciar um novo ambiente Codespace;
- Edite os arquivos diretamente no Codespace e, ao finalizar, faça o commit e o push das alterações.
